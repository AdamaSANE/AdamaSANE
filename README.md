## 🚀 Projets Phares

### 1. [DaaS Micro-Scoring](https://github.com/AdamaSANE/LIEN_VERS_REPO) 
*Plateforme de micro-scoring financier orientée "Data as a Service".*
- **Architecture :** Conception d'une API RESTful complète de bout en bout.
- **Technologies :** Python, FastAPI, Docker.
- **Impact :** Conteneurisation intégrale pour des déploiements fluides et intégration de tests unitaires rigoureux garantissant la fiabilité des modèles de scoring.

### 2. [CineScope](https://github.com/AdamaSANE/LIEN_VERS_REPO)
*Moteur d'analyse de sentiments par Intelligence Artificielle (NLP).*
- **Architecture :** Entraînement et fine-tuning de modèles Transformers sur le dataset IMDB.
- **Technologies :** PyTorch, Hugging Face (Tokenizer `bert-base-uncased`), Python.
- **Impact :** Classification binaire haute performance avec scripts d'inférence personnalisés pour des évaluations rapides.

### 3. [Jokko Platform](https://github.com/AdamaSANE/LIEN_VERS_REPO)
*Infrastructure Backend asynchrone pour plateforme web.*
- **Architecture :** Déploiement de l'environnement de base de données et gestion avancée des migrations.
- **Technologies :** Python 3.13, PostgreSQL, AsyncPG, Alembic.
- **Impact :** Optimisation des performances via des connexions asynchrones et sécurisation des évolutions de schémas de données.
